노트북에서 연도별 트리 수와 Brier Score를 확인할 수 있습니다. 기본 실행은 합성 데이터 CPU 데모입니다.

## 트리 수 선택을 여러 시즌으로 확장

**문제 발견.** 기존 모델(M1)은 평가 직전 한 시즌의 결과로 트리 수를 골랐습니다. 이 방식으로 2024년 평가 모델에 트리 1개가 선택되어, 한 시즌의 결과에 의존하는 선택 방식을 점검했습니다.

**변경.** M2에서는 평가 연도보다 앞선 검증 시즌들을 대상으로 트리 수 후보별 평균 Brier Score를 계산했습니다. 평균이 가장 낮은 트리 수를 고른 뒤, 평가 직전까지의 데이터로 모델을 재학습했습니다. 예를 들어 2024년 모델은 2020–2023년 검증 결과에서 트리 수를 선택하고 2019–2023년 데이터로 학습한 다음 2024년 투구에 적용했습니다.

**검증.** 두 모델에서 CatBoost 입력 변수 46개와 2021–2024년 평가 구간을 동일하게 유지했습니다. 각 시즌은 해당 시즌 이전 데이터로 학습한 모델로 예측했고, 네 시즌의 총 **993,592건**을 합쳐 Brier Score를 계산했습니다. Brier Score는 예측 확률과 실제 이진 결과의 평균제곱오차로, 낮을수록 좋습니다.

| 모델 | 트리 수 선택에 사용한 검증 결과 | 2021–2024 내부 검증 Brier Score |
| --- | --- | ---: |
| M1 | 직전 한 시즌 | 0.24841739 |
| M2 | 평가 이전 시즌들의 평균 | **0.24792029** |
| 변화량 (M2 − M1) | | **−0.00049710** |

## 후속 실험과 판단

아래 비교는 실험별 기준 모델과 평가 범위를 기준으로 했습니다. ΔBrier는 후보 점수에서 해당 실험의 기준 점수를 뺀 값입니다.

| 실험 | 관찰한 결과 | 판단 |
| --- | --- | --- |
| 선수 ID 제외 및 경기 상황 변수 추가 (CPU A-core) | 해당 실험의 Full46 기준 대비 통합 Brier가 0.24832432에서 0.24824410으로 하락 | 후속 CPU 실험의 기준 모델로 채택 |
| 최근 시즌에 더 큰 가중치 부여 | 비교 구간에서 최근 3개 시즌을 사용한 모델보다 Brier가 0.00003573 높음 | 기존 방식 유지 |
| 경기 유형별 확률 혼합 보정 | A-core 대비 내부 ΔBrier는 −0.00031832였으나, DACON Public 점수는 A-core 870.0012에서 보정 모델 866.2678로 하락 | 제출 기준 모델로 A-core 유지 |
| 최근 투구 기록을 이용한 잔차 보정 | 개선이 2023년에 집중됐고 2024년 Brier는 악화 | 시간에 따른 성능 변화를 진단하는 데 활용 |
| 파생변수 표현 변경 및 추가 7안 | 첫 84회 학습은 기준 모델과 트리 수 설정이 달라 비교에서 제외. 설정을 맞춰 재검증하니 6안은 탈락했고, 맞대결 이력 1안은 효과가 작고 시드별 결과가 불안정했음 | 기존 변수 유지 |
| CatBoost 하이퍼파라미터 탐색 | 일부 최신 시즌 결과가 개선됐지만 검증 시즌별 Brier를 같은 비중으로 평균하면 비교 후보 모두 악화 | 기본 설정 유지 |

후속 실험에서는 비교 전에 입력 변수, 검증 연도, 시드, 트리 수를 확인했습니다. 채택 여부를 판단할 때는 전체 평균과 함께 연도별 개선 방향, 가장 크게 악화한 연도, 실제 제출 결과를 확인했습니다.
